Due to licensing restrictions, we cannot release the data from TACREV. However, here are the instructions for creating the data used in our evaluation:

After obtaining the TACREV dataset, put the "dev.json" and "test.json" files from TACREV in this directory. Then run the "create_data.py" script. After running the script, the following files should be added to this directory:
- dev.0.01.json
- test_subset.json
